# ACML 2026 Workshop — OE-Agent

**Open and Efficient Agentic AI for Resource-Constrained Environments: Advancing Accessible AI Beyond Frontier Models**

Official website: [https://acml2026-oeagent.github.io](https://acml2026-oeagent.github.io)

This Jekyll site is based on code from [neurips2023-bugs.github.io](https://neurips2023-bugs.github.io) and has been adapted for the OE-Agent workshop at ACML 2026.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:4000` to preview the site.
